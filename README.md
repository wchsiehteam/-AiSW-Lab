# AiSW Lab 網站

東吳大學社會工作學系謝文中老師研究室（AiSW Lab）的官方網站。

- 網站網址：https://wchsiehteam.github.io/-AiSW-Lab/
- 架設方式：GitHub Pages（免費，存檔後約五分鐘自動更新）

## 檔案說明

| 檔案 | 用途 | 需要改嗎 |
| --- | --- | --- |
| `content.js` | 網站上所有文字：關於我們、成員、研究發表、產品、聯絡資訊 | **平常只改這個** |
| `index.html` | 版面與樣式 | 不用動 |
| 照片檔（如 `123.jpg`） | 成員照片 | 新增成員時上傳 |

## 修改文字

1. 在本頁上方點開 `content.js`。
2. 按右上角的鉛筆圖示（Edit this file）。
3. 只改雙引號 `" "` 裡面的字。
4. 按右上角綠色的 **Commit changes...**，跳出視窗後再按一次 **Commit changes**。
5. 等約 1 分鐘，打開網站，按 `Cmd + Shift + R`（Windows：`Ctrl + F5`）強制重新整理，就會看到新內容。

## 新增一筆資料

例如多一篇論文、多一位成員、多一家合作醫院：

1. 複製上面一整筆 `{ ... },`（從 `{` 到 `},`）。
2. 貼在它下面，再改裡面的字。
3. 每一筆後面都要有逗號 `,`，最後一筆可以不加。

## 新增論文或研究計畫

研究發表依類別分組（研究計畫、期刊論文、研討會論文、專書論文），每一筆就是一行文字：

1. 在 `content.js` 找到對應類別的 `items: [`。
2. 在第一行上方貼上新的一行，格式是 `"論文的完整書目",`（雙引號包起來，後面加逗號）。
3. 新的放最上面；每類只先顯示前 5 筆，其餘會收在「顯示其餘」裡。

## 放成員照片

1. 回到本頁，按 **Add file** → **Upload files**，把照片拖進去，再按 **Commit changes**。
   檔名請用英文，例如 `123.jpg`。
2. 到 `content.js`，把該成員的 `photo: ""` 改成 `photo: "123.jpg"`。

## 更新產品狀態

在 `content.js` 的 `products` 裡：

- `status` 寫 **開放使用**：顯示紅底，並出現「開啟」按鈕（`url` 要填網址）。
- `status` 寫其他文字（例如 **研究試用中**）：顯示白底標籤，不會有按鈕。

## 改壞了怎麼辦

網站某一區突然變空白，通常是**少了逗號或引號**。

1. 點開 `content.js`，按右上角 **History**。
2. 找到上一個正常的版本，點進去複製全部內容。
3. 回到 `content.js` 編輯，整份貼上後 Commit，就恢復了。

## 共編成員

要加入編輯，請先註冊 GitHub 帳號，再請管理者到 **Settings → Collaborators → Add people** 邀請。

## 如果真的不會改

內容文字問題：將content.js複製起來貼給AI，請AI修改

版面問題：將index.html複製起來貼給AI，請AI修改
