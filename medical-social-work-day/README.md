# 醫務社工的一天 · 體驗版

一個用瀏覽器就能玩的 3D 醫務社工遊戲。你是醫院的醫務社工師，一個人負責整層病房，從 08:00 上班到 17:30。護理師會打電話來照會：有的只是家屬問問題，有的背後是家暴、是一個撐不下去的家庭。到了床邊，用選的決定怎麼做；選錯，個案的狀況會變糟。吃飯、午休、上廁所，都得自己找空檔。

以《我熱愛值班》一般民眾版範本（drcharming.net）改編：保留 3D 病房、電話分流、床邊選擇的引擎，改成白班、社工的評估指標和五個社工個案。

- 不用安裝任何套件，不用打包，純 HTML + JavaScript（three.js 已經放在專案裡）
- 手機、平板、電腦都能玩（手機要橫著拿）
- 只能非商業使用、要標示出處，詳見下面的〈授權〉

## 先玩玩看

需要 [Node.js](https://nodejs.org/) 18 以上：

```bash
npm start
```

打開它印出來的網址（`http://127.0.0.1:8790/`）。沒有 Node.js 的話，用 Python 也可以：`python -m http.server 8790 --bind 127.0.0.1`。直接雙擊 `index.html` 不行，一定要透過伺服器。

## 和原本的範本差在哪

| 原範本（值班醫師） | 這個版本（醫務社工） |
|---|---|
| 17:00 值到隔天 08:00 | 08:00 上班到 17:30 |
| 晚餐便當、半夜睡覺 | 午餐便當、午休 |
| 床邊監視器：心跳、血壓、血氧 | 五格評估：人身安全、照顧與支持、經濟、情緒、時限 |
| 抽血，30 分鐘後出報告 | 送出查詢（戶政、警政、福利身分、保護資訊系統），20 分鐘後回覆 |
| 心跳停止、壓胸小遊戲 | 拿掉了。錯太多，個案就走向 `fail` 的結局 |
| 兩床範例病人 | 五個個案：家暴、出院準備、經濟扶助、安寧家庭會議、身分不明的走失長者 |

## 一天怎麼進行

1. **開始卡**：輸入暱稱、選普通班或大爛班、選你的樣子。
2. **晨會**：社工組長交代幾個進行中的個案（都是隨機的，今天不用處理），按「開始上班」時間才開始走。
3. **上班**：
   - 電話響了，有三種答法：**過去看看**、**電話交代**、**先不管**。只能從護理師說的話判斷是小事還是危機。
   - 是小事卻跑去看，會「白跑一趟」；是個案卻沒去，狀況會變糟，護理師會再打來。
   - 到了床邊，每一題選一個做法。選對往下走；選錯會劃掉、說明為什麼，狀況變糟，錯太多就接不住了。
   - 精力、肚子、尿意會一直變。精力低於 20% 跑不動，歸零就累倒，今天結束。
4. **結算**：接住幾個個案、接了幾通電話、幾通其實電話講就好，加上每個個案「你可以記住的事」。可以分享成限時動態大小的圖卡。

### 個案什麼時候打來

`game.js` 的 `NIGHT_SLOTS` 決定時段（名稱沿用範本）。普通班想要 4–6 個、大爛班 6–8 個，但不會超過 `PUBLIC_CASES` 裡有的數量。現在有五個，所以兩種班都是 4–5 個。

| 順序 | 時段 | 說明 |
|---|---|---|
| 1 | 午餐 | 便當吃到一半打來（一直沒去吃的話，13:00 也會打來） |
| 2 | 14:00–14:40 | 下午 |
| 3 | 08:40–09:10 | 剛上班 |
| 4 | 午休後 | 先響兩通小事，再來這一個 |
| 5 | 16:00–16:30 | 下班前 |
| 6 | 09:50–10:30 | 早上 |
| 7 | 11:00–11:30 | 中午前 |
| 8 | 15:00–15:30 | 下午 |

個案寫了 `night: true`（例如醫師排在下午的家庭會議），只會排到 13:30 以後的時段。另外每天一定有：早上兩通小事、午休一通、午休後兩通、下班前兩通。

## 加一個個案

1. 打開 `game/public-cases.js`，複製一個個案（例如 `DV`）整段，改名。
2. 改 `id`（不能重複，習慣用 `p` 開頭）和 `bed`（從下面「可以用的床號」挑一個沒人用的）。
3. 改人物、電話、床邊的對話、五格評估的狀態（`states`）、題目（`steps`）、查詢結果（`labs`）、衛教卡（`card`）、失敗的結局（`fail`）。
4. 加到最下面的 `PUBLIC_CASES`。
5. 跑 `npm test`，照它說的修。
6. `npm start`，網址加 `?debug`，玩一天看看（見下面〈測試〉）。

### 一個個案的欄位

| 欄位 | 是什麼 |
|---|---|
| `id`, `bed`, `nurse`, `name`, `who` | 個案是誰、在哪一床、哪位護理師（怡君、小雯、佳穎） |
| `short` | call 欄上的一行字 |
| `night` | `true`：只排在午休後 |
| `call` | 第一通電話，用「社工師，」開頭。`{bed}` 會換成床號 |
| `again` | 社工沒來，護理師第二通電話（狀況變糟了），用「社工師！{bed} 」開頭 |
| `phone`, `callWhy` | 電話上可以怎麼交代（看起來像小事的答法），以及為什麼這個一定要有人去 |
| `intro`, `introLate`, `late` | 到床邊時護理師說的話；拖太久才來時說的話，和那時的狀態 |
| `states` | 五格評估：`safe`（人身安全）、`care`（照顧與支持）、`money`（經濟）、`mood`（情緒）、`clock`（時限），每格寫 `[文字, 等級]`，等級是 `''`（沒問題）、`'warn'`、`'bad'`、`'na'`（還不知道）。`start` 要寫齊五格，其他狀態沒寫的格子沿用上一次 |
| `steps` | 題目。第一題叫 `first` |
| `warn` | 危險度到 3 時的警訊（狀態、護理師喊的話、紀錄） |
| `fail` | 危險度到 5（或選項寫 `next: 'fail'`、`death`）時怎麼結束：`title` 和 `text` |
| `results` | 每種結局一句話，例如 `{ stable: '林小姐有了安全計畫' }` |
| `labs` | 查詢結果：`rows` 是 `[查了什麼, 結果, 說明, '!']`（`'!'` 代表要留意），`note` 是白話說明 |
| `card` | 結算時「你可以記住的事」：`title` 和幾點 `points` |

### 一個題目、一個選項

```js
first: {
  ask: '林小姐的先生一直在旁邊替她回答。你先做什麼？',
  askWarn: '她先生在吼著要帶她走。你先做什麼？',   // 在警訊狀態（或拖太久才到）時改問這句，可省略
  options: [
    { id: 'alone', text: '請先生到外面等，單獨跟林小姐談', grade: 'best', min: 3, state: 'alone', next: 'talk',
      say: '門關上後，林小姐的肩膀才放鬆下來。' },
    { id: 'ask', text: '當著先生的面問：「是不是有人打你？」', grade: 'bad', min: 3, state: 'scared',
      say: '林小姐馬上說：「沒有啦。」', why: '施暴者在場時直接問，受害者只能否認。' },
  ],
},
```

- `grade`：`best` 往下走；`ok` 危險度 +1、`bad` +2，選項會被劃掉並顯示 `why`。危險度 3 出現警訊，5 走 `fail`。
- `min`：這個做法花幾分鐘，會算進時鐘。
- `next`：下一題的名字，`'done'` 結束（要配 `outcome`，對到 `results`），`'fail'` 直接失敗。
- `state`：選了之後五格評估變成哪個狀態。
- `say`：護理師或旁白接著說的話。
- `death`：選了就直接失敗，寫為什麼。
- `draw: true`：這個做法順便送出查詢，結果 20 分鐘後回覆。
- 一題最多四個選項。畫面上的順序每次都會打亂。

### 可以用的床號

只有這幾間房的床可以響（每間 A、B、C 三床）：`03` `04` `06` `07` `08` `11`。要開放別間，把房號加到 `game.js` 的 `CASE_ROOMS`。護理師的分區：怡君 01–04、小雯 05–08、佳穎 09–12。

## 加一通小事電話

小事在 `public-cases.js` 最上面：`PUBLIC_CALLS`（早上兩通、午休後兩通，標 `night: true` 的只在午休後）、`DEEP_CALLS`（午休）、`DAWN_CALLS`（下班前）。`need` 是 `'none'`（不理也沒事）或 `'phone'`（電話交代最好）；`visit` 是社工真的跑去看時演的那一幕，寫在 `game.js` 的 `CASES` 裡（`'v-...'`）。

## 角色立繪

`assets/game/char/` 裡是 `tools/make-placeholders.mjs` 畫的佔位圖。玩家的檔名沿用範本的 `pgy_m_`／`pgy_f_`，畫的是穿開襟衫、掛識別證的社工。換成你自己的圖時，照同樣的檔名放進去，建議 600×800、背景透明。

## 測試

```bash
npm test
```

檢查 `public-cases.js`：欄位有沒有漏、`next` 指到的題目在不在、五格評估寫得對不對、床號能不能用、一路選 best 能不能走完、每個結局有沒有選項會走到，最後模擬一千天，告訴你一天會排到幾個個案。

在瀏覽器裡測：網址加 `?debug`，按 `]` 時間快轉 30 分鐘；主控台有 `window.__ward`（`__ward.S` 是整天的狀態，`__ward.step(n)` 往前跑 n 格畫面，`__ward.openPublicCase('pdv')` 直接打開某一個個案）。

## 內容審閱

個案是寫給一般民眾和社工系學生的教學劇情，不是實務指引，人物都是虛構的。法規、通報流程和資源的寫法（家暴責任通報、出院準備銜接長照、急難救助、安寧緩和醫療、愛心手鍊等），上線前請督導或授課老師看過。開始畫面的提醒（119、113）請保留。
